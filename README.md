# 🩷 Minha Lista de Tarefas

Uma aplicação simples de lista de tarefas desenvolvida em PHP, HTML e CSS para a Agenda 04 de Desenvolvimento de Sistemas II.

## 📋 Sobre o projeto

A aplicação permite cadastrar tarefas informando seu nível de prioridade. As tarefas são organizadas e apresentadas na tela após o cadastro.

O projeto foi desenvolvido com foco na utilização de **funções** e **estruturas de repetição em PHP**.

## 💻 Tecnologias utilizadas

- PHP
- HTML5
- CSS3

## ⚙️ Funcionalidades

- Cadastro de tarefas;
- Seleção de prioridade;
- Exibição das tarefas cadastradas;
- Utilização de função para organizar os dados;
- Utilização de `foreach` para percorrer e exibir as tarefas;
- Interface personalizada.

## 🎯 Conceitos aplicados

A função `adicionarTarefa()` recebe o nome da tarefa e sua prioridade e organiza essas informações.

A estrutura de repetição `foreach` percorre a lista de tarefas e apresenta cada item na página.

## 🎨 Desenvolvimento

A interface foi personalizada com uma identidade visual em tons de rosa, branco e preto, buscando criar uma apresentação simples, organizada e agradável.
